# Long aligned formatting example

This fixture deliberately exceeds a typical alignment encoder window. Review the entire translated passage, not just its first sentence.

**The translation service reads each paragraph and keeps its formatting information separate from the words sent to the language model. Before processing a long passage, the application measures its input and selects boundaries that preserve complete words and protected content. Each translated passage remains associated with the source passage that produced it, even when the German words appear in a different order. An alignment method identifies corresponding expressions, but the reviewer must still check repeated terms and phrases whose meaning depends on context. When a phrase cannot be assigned reliably, the application records a warning and retains the translated text without the affected formatting. The final document should preserve links, code examples, headings, and the distinction between ordinary text and passages that require special attention.
