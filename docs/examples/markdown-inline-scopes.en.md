# Formatting within sentences

## A: Short emphasis

The **classification model** processes *new observations* and predicts a category.

## B: Discontinuous emphasis

She **turned off** the light before leaving the room.

## C: Discontinuous link

She [turned off](https://example.org/switch "Switch instructions") the light before leaving the room.

## D: Repeated words

The first model checks the **second model**, and the second model checks the first model.

## E: Independent links

Read the [user guide](https://example.org/guide "User guide") before opening the [settings panel](https://example.org/settings "Settings panel").

## F: Nested emphasis

The **new *classification* model** processes observations quickly.

## G: Protected content inside emphasis

Keep **the expression `model.predict(data)` unchanged** before reviewing the result.

## H: HTML link

She <a href="https://example.org/switch?mode=manual&amp;step=1" title="Keep this title unchanged.">turned off</a> the light before leaving the room.

## I: Formatting across a sentence boundary

The first model **works reliably. The second model** needs more data.
